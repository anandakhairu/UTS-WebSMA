# Website Profil SMA Negeri 1 Manggar

link: https://uts-web-sma-rose.vercel.app/

## Halaman
- `/` Beranda (banner, tentang singkat, sambutan, berita terbaru)
- `/about` Profil Sekolah (video, sejarah, logo), lalu sub-halaman Visi & Misi, Kepala Sekolah, Fasilitas, Ekstrakurikuler, Alamat
- `/berita` Semua berita, dan `/berita/[id]` Detail berita
- `/kegiatan` dan `/prestasi/siswa`, `/prestasi/guru`

## Komponen
Navbar, Footer, Hero, BeritaCard, Button, SectionTitle, SideMenu, PageTitle, Foto, Icon.

## Menjalankan
npm install
npm run dev
